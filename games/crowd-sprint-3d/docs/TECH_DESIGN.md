# CROWD SPRINT（3D 版）技術設計とベンチマーク計画（2026-11-22）

**方針**：800 人全員を実際の 3D モデルで描く。2D スプライト化・Canvas 2D の疑似 3D・人数削減はしない。ルールと順位の計算は既存版（`games/crowd-sprint`・2D 比較版）から**変えない**。最初から完成版として設計し、iPhone で快適に動く軽さを最優先にする。

## 1. 技術の選定
| 候補 | 長所 | 短所 | 判断 |
|---|---|---|---|
| **素の WebGL2（採用）** | 外部ライブラリ・ダウンロード不要（権利の台帳が単純）。必要な機能だけなので軽い（JS 数十 KB）。インスタンス描画・頂点シェーダーでのアニメーションを完全に制御できる | シェーダー・行列・バッファ管理を自前で書く | **採用**。800 人×1 種類のモデルという用途に最も合う。iOS Safari 15 以降で WebGL2 が使える |
| three.js（MIT） | 便利。InstancedMesh あり | 約 600KB 以上のダウンロードと同梱が必要（外部ファイルの取得は承認制）。汎用のオーバーヘッド。スキンメッシュ 800 体は CPU が重い | 不採用 |
| WebGPU | 新しい | iOS の対応が限定的。不安定 | 不採用 |
| Canvas 2D の疑似 3D／スプライト | 軽い | **禁止（絶対条件）** | 不可 |

## 2. 描画設計（800 人＋プレイヤー）
- **ジオメトリ**：人型を低ポリゴンの箱と球で、コードから生成（外部モデルなし。権利は自作）。パーツ 11 個（骨盤・胴・頭・上腕×2・前腕×2・太もも×2・すね×2＋靴）。
- **LOD（3 段階。遠くも必ず 3D のモデル）**：LOD0（〜18m）約 220 三角形・LOD1（〜45m）約 100・LOD2（それ以遠）約 50。ビルボードや画像への置き換えはしない。
- **GPU インスタンシング**：LOD ごとに 1 回の `drawElementsInstanced`（合計 3 回）。インスタンスの属性は 12 float（位置・向き・走りの位相・傾き・振りの大きさ・腕上げ・膝の曲げ・色・大きさ・主人公フラグ）。毎フレーム `bufferSubData` で 3 つのバッファを更新（最大約 38KB）。バッファは起動時に 1 度だけ確保して**再利用**（毎フレームの割り当てなし）。
- **アニメーションは頂点シェーダー**：骨格は持たない（CPU のスキニングなし）。頂点にパーツ番号を持たせ、シェーダーが関節（肩・肘・股関節・膝）の回転を、インスタンスごとの位相から計算する。走り・転びかけ・転倒・起き上がり・ジャンプ・ダッシュの前傾を、少数のパラメーターで表現。
- **フラスタムカリング**：CPU で、カメラの視錐台に入らないランナーを除外（インスタンスバッファに入れない）。
- **影**：丸い影のインスタンス（1 回の描画）。**コース**：1 枚の地面のシェーダーで模様・レーン・スタートとゴールの線を描く（テクスチャなし）。**背景**：空は全画面 1 枚のシェーダー（太陽つき）。柵・観客席（観客はブロック）・ゴールゲート・遠景のビルは、起動時に 1 つの静的バッファへ結合して 1 回で描く。
- **描画コール**：地面 1＋空 1＋静的な背景 1＋影 1＋ランナー 3＝**約 7 回**。HUD は、別の透明な Canvas 2D（3D の上に重ねる。文字と数字だけで軽い）。
- **フラグメントは軽く**：ランバート＋半球の環境光＋フォグだけ。テクスチャなし。**アンチエイリアスはオフ**（スマホで高コスト）。代わりに**動的な解像度**：直近のフレーム時間を見て、描画の解像度（スケール）を 1.0〜0.5 の間で自動調整（遅いときは下げ、余裕があるときは戻す）。画素密度の上限は 2。

## 3. シミュレーション
`sim.js`（TypedArray・空間ハッシュ・簡易な円の衝突）は 2D 比較版と**同じルール**。描画用にアニメーション状態の配列を足すだけ（ルール・順位の式・数値は不変）。3D 版の `sim.js` は、2D 版と同じ入力で**同じ結果になること**をテストで保証する。

## 4. 計測の設計（ヘッドレス Chrome の数値だけで合格にしない）
| 指標 | 取り方 | 状態 |
|---|---|---|
| FPS・フレーム間隔（平均・p95・最悪） | `requestAnimationFrame` の間隔を、ゲーム内（`?perf=1`）で常時記録 | 実装。**実機は未計測** |
| CPU フレーム時間 | 更新＋インスタンス構築＋描画の呼び出しの時間（`performance.now()`） | 実装。**実機は未計測** |
| GPU フレーム時間 | `EXT_disjoint_timer_query_webgl2`（Chrome）。**iOS Safari には無い** | Mac の GPU では計測可。**iPhone は不可 → Safari の Web インスペクタ／Xcode の Instruments（Metal System Trace）で、実機を接続して計測**（承認が必要） |
| メモリ | JS ヒープ（`performance.memory`、Chrome のみ）。GPU バッファの確保量は自前で正確に集計（テクスチャなし）。iPhone は Xcode の Instruments（Allocations）で計測 | 一部実装。**実機は未計測** |
| 発熱 | ブラウザからは測れない。ベンチを 3 分×連続で走らせ、**最初の 30 秒と最後の 30 秒の FPS を比較**（サーマルスロットリングの目安）＋実機の手触り・本体の温度の申告 | ベンチ実装。**実機は未計測** |
| 入力遅延 | 入力イベントの `timeStamp` から、その入力を反映したフレームの描画投入までの時間（ブラウザ内で測れる範囲。表示までの遅延は含まない） | 実装。**実機は未計測。表示までの遅延は高速カメラが必要** |
| 描画の構成 | 描画コール数・三角形数・インスタンス数（LOD 別）・バッファの大きさ | 実装（決定的な数値。実機でも同じ） |

### ベンチ（`?bench=1`）
ボットが 1 レースを自動で走り、1 秒ごとに上の指標を記録し、終了時に結果の表（コピーできる文字列）を出す。`&loop=N` で N 回（約 25 秒ずつ）繰り返し、発熱の目安を取る。`&scale=0.75` で解像度を固定して比べられる。
### 実機の測り方（承認が必要。iPhone を接続して行う）
1. Mac で `python3 tools/serve.py --lan` を起動（同じ Wi-Fi の端末だけがアクセスできる。終わったら止める）。2. iPhone の Safari で `http://<MacのIP>:8790/crowd-sprint-3d/?bench=1&loop=7`（約 3 分）。3. 表示された結果を共有してもらう（または Safari の Web インスペクタで、Mac から接続して Timelines・Graphics を記録）。4. 本体温度の変化と手触りを申告してもらう。
### 合格の基準（目標。実機で確認するまでは「未達成」と扱う）
iPhone 実機（目標：A14 以降の機種。具体の機種はあなたが決める）で、800 人表示のレース全体で、**平均 58fps 以上・p95 のフレーム間隔 20ms 以下・3 分連続でも FPS の低下 10% 以内**。

## 5. 保守性
既存の 2D 版は**比較用に保持**（`games/crowd-sprint`。題名に「2D 比較版」と明記）。3D 版は `games/crowd-sprint-3d` として**独立**（`play/sim.js` も別ファイル）。共通基盤（`platform/`）には、WebGL を使うゲームのための**汎用の口**だけを足す（描画用 Canvas の追加・フレーム統計）。

## 6. 権利
外部ライブラリ・外部モデル・外部テクスチャ・外部フォントは使わない（すべて自作のコードと数式）。台帳：`ASSET_LICENSES.md`。

## 7. 実装メモ（2026-11-22 追記）
- **順位**（ユーザーの指示）：実際の順位（主人公を含めて 800 人。最後尾＝800 位）。それ以外のルールの数値は 2D 比較版と同じ。主人公の枠（最後列の中央）の NPC を置かず、NPC は 799 人。
- 実装：`play/gl/`（`math.js`・`model.js`・`world.js`・`renderer.js`）、`play/sim.js`、`play/main.js`、`play/bot.js`。外部ライブラリなし。
- 共通基盤への追加（`platform/core/runtime.js`）：`def.gl`（WebGL2 の Canvas を 2D の下に重ねる。非対応のブラウザには、2D に置き換えず「WebGL2 が必要」と表示）、フレーム統計（FPS・CPU・入力遅延）、`input.takeStamp`。
- 計測の道具：`?perf=1`・`?bench=1&loop=N`・`?scale=`・`?only=`（描画要素を絞る切り分け用）・`tools/cdp.py`・`tools/serve.py --lan`。結果と限界は `BENCHMARK.md`。
