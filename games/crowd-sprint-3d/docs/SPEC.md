# 仕様：CROWD SPRINT（3D 版）

2D 比較版（`games/crowd-sprint`）のゲーム性を維持する。**ユーザーの指示（2026-11-22）で、順位だけ「実際の 800 人の順位」に変えた。**

## 維持するもの
最後尾からスタート／左右移動／ジャンプ／DASH／スタミナ／ふらつきと転倒／転倒の連鎖（同時に 45 人まで）／スリップストリーム／NPC がプレイヤーをよける／必ずゴールできる／約 20 秒で 1 レース／日本語のメダル。移動・接触・転倒・ドラフト・スタミナの数値と挙動は、2D 版と同一（テストで、数値の表の一致と、同じボットのタイムが近いことを確認）。

## 変えたもの（ユーザーの指示）
| 項目 | 2D 比較版 | 3D 版 |
|---|---|---|
| 出走者 | NPC 800 人＋主人公 | **主人公を含めて 800 人**（NPC 799 人。主人公の枠は最後列の中央） |
| 順位 | 演出の人数 8,888,888 を使った式（最後尾＝約 888 万位） | **実際の順位**＝自分より前の人数＋1。**最後尾＝800 位、1 位＝誰にも抜かれていない** |
| メダル | TOP 100 万 〜 優勝 | 完走／上位半分（400 位以内）／TOP 200／100／50／10／表彰台（3 位以内）／優勝 |
| 結果の表示 | 追い抜いた人 約 888 万人 | 追い抜いた人 N 人（全 800 人中） |
| 表現 | Canvas 2D の疑似 3D（スプライト） | **WebGL2 の 3D。全員が 3D モデル**（LOD3 段階。2D への置き換えなし） |

## 3D の表現
- ランナー：低ポリゴンの人型（頭・胴・腕・脚・靴）。LOD0（〜18m）約 244 三角形／LOD1（〜45m）96／LOD2 48。遠くも 3D のまま。
- 動き：走り（位相・腕と脚の振り・膝の曲げ・前傾）、ふらつき、転倒（前のめりに倒れる→横たわる）、起き上がり、ジャンプ（膝を抱える）、ダッシュの前傾。すべて頂点シェーダー。
- コース：夕焼けの空と太陽、5m ごとの縞のトラック、レーン線、スタートとゴールの線、両側の柵、観客席（観客はブロック）、ゴールゲート、遠景のビル。
- カメラ：後ろ上から追う。ダッシュで視野が広がり、転ぶと引き、開始前は群衆を見渡し、ゴール後は主人公の前へ回り込む。小さな揺れ（`prefers-reduced-motion` では抑える）。主人公の頭上に目印（人混みで見失わない）と足元の輪。
- HUD：3D の上に重ねた 2D（順位の大きな数字・進行バー・スタミナ・ふらつき・ボタン）。数字と文字だけ。

## 操作
PC：← → 移動／Shift ダッシュ／Space ジャンプ／M ミュート。スマホ：なぞって移動＋DASH・JUMP ボタン（マルチタッチ）。
