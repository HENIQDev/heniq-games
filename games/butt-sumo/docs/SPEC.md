# BUTT SUMO 仕様（実装済みの内容）

## ルール
- 円形の土俵（半径 5.0 m）で 1 対 1。相手を土俵の外へ出せば勝ち。制限時間 60 秒（40 秒から土俵が最大 40% 狭くなる）。
- 時間切れは、①「勢い（ダメージ）」が 6 以上少ない方、②中心に近い方（差 0.4 m 超）、③引き分け。
- 固定 30 Hz のシミュレーション（`play/sim.js`）。CP 戦はブラウザ、オンライン対戦はサーバーが、同じ `step()` を実行する。

## 操作
| 操作 | PC | スマホ | 動作 |
|---|---|---|---|
| 移動 | WASD／矢印 | 左の仮想スティック | 自動で相手にお尻を向ける（旋回速度はキャラごと） |
| 突進 | Space／J／Z | 突進ボタン | スティック方向（なければ相手方向）へ、お尻から。スタミナ 22、クールダウン約 1〜1.3 秒 |
| 踏ん張り | Shift／K／X（押している間） | 踏ん張りボタン | 被ダメージ・吹っ飛びを大きく軽減。押した直後 0.3 秒の被弾は「ジャスト」＝弾き返して相手を 0.75 秒スタン |
| チャージ | C／L（長押し→離す） | チャージボタン | 最大 1.1 秒ため、離すと強い突進。ため中は遅く、被弾で中断 |
| 必殺 | E／Enter／U | 必殺ボタン | ゲージ 100 で発動。ゲージは「当てる／当てられる／時間」で溜まる |
| ポーズ | P／Esc | 画面の II | CP 戦のみ（オンラインは止められない） |
- ゲームパッド（標準配置）も使える（検証は未実施）。連打対策：突進のクールダウン（外すと延びる）・スタミナ・踏ん張りの再入力待ち 0.4 秒。

## 物理
- 円と円の衝突。位置の補正は質量で配分（踏ん張り中は質量 3 倍扱い＝押し合いで有利）。
- 「お尻の当たり」だけがダメージと大きな吹っ飛びを生む：攻撃中（突進・回転・スライド）で、お尻の向きと接触方向の差が約 57° 以内。それ以外は弾性衝突のみ。
- 吹っ飛び = 威力 × 基本値 ×（1 + 勢い × 0.009）÷（質量^0.4 × 防御^0.35）。速度は減衰（踏ん張り中は強く、プリンや氷の床は弱く）。
- 場外：中心からの距離 > 土俵の半径 + キャラ半径の 15%。場外後は回転しながら落下。
- 調整値は `sim.js` の `TUNE`（kb 4.0／dmgScale 0.009／hitDmg 4.5／dashRest 1.0）。

## キャラクター（10 体）
性能は `play/chars.js`、3D モデルは `play/gl/models.js`。必殺技は 8 種（回転は 2 体が共有、謎の生物は毎回ランダム）。
| キャラ | 特徴 | 必殺技 |
|---|---|---|
| おじさん | バランス型 | 全力ぶちかましヒップ（超パワーの長距離突進） |
| ニワトリ | 軽量・高速・吹っ飛びやすい | バサバサ飛び乗り（飛び上がって相手の内側へ着地し、外へ押す） |
| ゴリラ | 重量級・強力・鈍足 | ドラミング地震（近距離の全方向ふっ飛ばし） |
| カエル | 軽〜中量・トリッキー | ベロベロ引き寄せ（相手を手元へ） |
| ハンバーガー | よく弾む | バンズ回転ヒップ（全方向に当たる回転） |
| プリン | 滑る操作感 | ぷるぷるスライド（氷のように滑りながら全身で当たる） |
| 寿司 | 超軽量・高速 | 回転寿司アタック（回転） |
| ロボット | 防御が高い・鈍重 | 装甲全開ズッシリ（3 秒間、重さ 2.4 倍・防御 1.8 倍） |
| 巨大な赤ちゃん | 巨体・大きな当たり判定 | 大泣きウェーブ（広範囲の吹っ飛び＋スタン） |
| 謎の生物 | 予測不能 | 毎回ちがう（他の必殺技から抽選。乱数はサーバー側＝公平） |

## CP ステージ（100）
`play/stages.js`。10 ステージ = 1 テーマ（公園・銭湯・神社・海辺・宇宙・氷の国・火山・ネオン街・食卓・天空）。クリア済み +1 のステージまで挑戦できる。進行は `localStorage` に保存。
- 難易度：CP の「反応間隔・攻め頻度・狙いのブレ・踏ん張り率・ジャスト率・端への意識」が段階的に上がる。能力値の上乗せ（攻撃 0.85→1.18、防御 0.9→1.2、速度 0.9→1.08）は控えめ。
- 行動パターン（tactics）：1–8 `rush`（突っ込むだけ）→ 9–16 +`chase` → 17–32 +`brace`・`counter`（突進を見て踏ん張る／スキを突く）→ 33–55 `feint`（回り込み）・`edge`（相手の内側へ回って外へ押す）→ 56–80 +`charge`・`special` → 81–100 すべて。
- ボス（10 ステージごと）：ドスコイ番長（押しの一手）／チキン将軍（ひき逃げ）／鉄壁ロボ・ガード（カウンター）／プリン姫（滑って回り込む）／ハンバーガー大王（回転ラッシュ）／ゲコ仙人（引き寄せと外押し）／ビッグ・ベビー（重量と大泣き）／大将寿司（高速フェイント）／ナゾ博士（全部入り）／大横綱 ミスター・ケツ（最終・体格 1.2 倍）。
- キャラ解放（クリアした時点）：ゴリラ 8／カエル 15／ハンバーガー 25／プリン 35／寿司 48／ロボット 62／赤ちゃん 78／謎の生物 92。初期はおじさん・ニワトリ。解放時に専用の演出（3D のお披露目）。
