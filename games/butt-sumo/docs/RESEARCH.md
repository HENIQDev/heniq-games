# BUTT SUMO 調査メモ

- **参考ゲーム**：今回の指示に、特定の参考ゲームの指定はなかった。「お尻で押し出す対戦」「相撲」「ぶつかり合い」は一般的な題材のため、既存の特定作品の見た目・文言・素材・数値は参照していない（`ASSET_LICENSES.md`）。実プレイによる参考ゲームの調査は行っていない。
- **ジャンルの定石として採用した一般的な仕組み**：ダメージが増えるほど飛びやすくなる（累積型の吹っ飛び）／ジャストタイミングの防御で反撃／ゲージが溜まる必殺技／制限時間での判定／終盤に土俵が狭くなる（サドンデス）。いずれも一般的な仕組みで、数値・演出・名称は独自。
- **独自の設計**：「お尻を自動で相手に向ける」「お尻の当たりだけが有効」「踏ん張りは質量 3 倍扱い」「CP は行動パターンで難易度を上げる」「謎の生物の必殺技はサーバー乱数」。
- **技術調査**：オンライン対戦は `ONLINE_DESIGN.md`。3D は raw WebGL2（外部ライブラリなし。`../crowd-sprint-3d/docs/TECH_DESIGN.md` と同じ方針）。
