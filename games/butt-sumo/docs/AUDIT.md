# BUTT SUMO 品質監査（2026-11-23）

方針：push・デプロイ・コミットはしない。ローカルで確認し、明確な不具合だけを修正。仕様・ゲーム性の変更は報告のみ。

## 実機・人間による確認が必要な項目（自動化できない）
1. iPhone Safari（実機）：タッチ操作の感触、拡大・スクロールの抑止、画面の回転、アドレスバー、WebGL2 の描画、FPS・発熱、音の再生制限。
2. Android Chrome（実機）。
3. 人間の実プレイ：操作感、各キャラの勝ちやすさ、CP の難しさ（特に 21〜40 の下がり方、ボス）、「面白いか」、負けた理由の分かりやすさ。
4. 音の聞こえ方（BGM・効果音のバランス・うるささ）。
5. Safari・Firefox・Edge での表示。
6. ゲームパッド実機。
7. スクリーンリーダー・色覚（HUD の色の区別）の確認。

## Cloudflare 本番でしか確認できない事項
Durable Object の WebSocket と Hibernation の実際の挙動／alarm／SQLite／無料枠の実測（リクエスト・Duration・行の読み書き）／同時接続数の上限／無料プランの CPU 制限が DO のタイマーに適用されるか／実際の遅延と通信量／Origin 検査／上限（150 接続・60 試合・800 試合／日）の動作／CSP の `connect-src`（`_headers` の `! Content-Security-Policy`）／デプロイ後の `config.js`・`network_hosts` の整合。

## 残るリスク
- **ゲームの面白さ・難しさが、人間で未検証**（最大のリスク）。代理の測定では、ニワトリ・プリン・寿司が「攻め方の癖」で有利不利が入れ替わる。
- スタミナの影響が小さい、必殺技の比重が大きい（場外の決着の 33〜69%）、重量級の「飛ばされにくさ」が弱い（`BALANCE_TEST.md` の 5.1。仕様判断が必要）。
- 匿名 ID が漏れた場合、その匿名の戦績の対戦・削除ができる（仕様上の限界）。ID を失うと戦績は復元できない。複数 ID での自作自演は防げない。不適切なニックネームのフィルターなし。
- オンラインは、遅延が大きい回線・切断が多い環境での体験が未検証。入力は約 90 ms 遅らせた補間描画で、手元の反応は往復の通信時間に依存する（予測なし）。
- Safari・Firefox・iOS 実機が未検証。iOS 15 未満は動かない。
- 無料枠の見積もりは、設計上の見積もり（実測ではない）。
